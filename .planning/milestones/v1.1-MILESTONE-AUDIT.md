- `main()` → `args.gui = False` → `_run_headless_mode()` → sensor loop → CSV write → terminal display → `KeyboardInterrupt` → `_print_summary()` → `sensor.close()` / `csv_logger.close()`
- **Status: COMPLETE** — direct port of v1.0 loop; 5 existing tests GREEN; zero regressions

**Flow 2: GUI acquisition** (`python main.py --gui`)
- `main()` → `args.gui = True` → `_run_gui_mode()` → deferred `from src.visualizer import PlotManager` → `PlotManager()` → daemon `_acquire` thread → per-reading: `csv_logger.write_row(reading)` + `pm.update_data(reading)` → main thread: `pm.start()` (blocking `plt.show()`) → window close → `_on_close` → `stop_event.set()` → `acq_thread.join(2)` → `_print_summary()` → `sensor.close()` → `csv_logger.close()`
- **Status: COMPLETE** — 5 new integration tests GREEN; 79/79 total tests pass
