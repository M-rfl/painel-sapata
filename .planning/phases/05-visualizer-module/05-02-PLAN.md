6. PlotManager class:

   __init__(self) -> None:
   - self._t_buf = deque(maxlen=MAX_POINTS)
   - self._t_start = time.monotonic()
   - self._channel_bufs: dict[str, deque] = {}
   - self._lines: list[tuple[str, object]] = []
   - self._fig, self._axes = plt.subplots(5, 1, figsize=(12, 10), constrained_layout=True)
   - try/except AttributeError around self._fig.canvas.manager.set_window_title("WTVB01 Live Sensor Data")
   - Loop over zip(self._axes, _SUBPLOT_DEFS):
     - ax.set_ylabel(ylabel)
     - ax.set_xlabel("Time (s)")
     - ax.grid(True, alpha=0.3)
     - For each (attr, label, color) in channels:
       - self._channel_bufs[attr] = deque(maxlen=MAX_POINTS)
       - line, = ax.plot([0], [0], color=color, label=label, linewidth=0.8)
       - self._lines.append((attr, line))
     - ax.legend(loc="upper left", fontsize="small")
   - self._ani = animation.FuncAnimation(
       self._fig, self._animate,
       interval=INTERVAL_MS,
       blit=False,
       cache_frame_data=False,
     )

   update_data(self, reading: SensorReading) -> None:
   - elapsed = time.monotonic() - self._t_start
   - self._t_buf.append(elapsed)
   - for attr, _line in self._lines:
     - value = getattr(reading, attr, None)
     - self._channel_bufs[attr].append(value if value is not None else float("nan"))

   _animate(self, frame) -> None:
   - t_snap = list(self._t_buf)
   - for attr, line in self._lines:
     - y_snap = list(self._channel_bufs[attr])
     - line.set_data(t_snap, y_snap)
     - line.axes.relim()
     - line.axes.autoscale_view()

   start(self) -> None:
   - """Block until window is closed. Call on main thread only (VIZ-01)."""
   - plt.show()

Anti-patterns to avoid (from research):
- Do NOT call tight_layout() inside _animate() — use constrained_layout=True at creation
- Do NOT use blit=True — axis limits and tick labels will freeze
- Do NOT assign FuncAnimation to a local variable — store as self._ani to prevent GC
- Do NOT call plt.show() from a background thread
- Do NOT use cache_frame_data=True (default) — causes memory growth in infinite animations
