Create `site/js/app/format.js` (pure ES module, no DOM, header comment "Pure module: no DOM/window").
- Build formatters once at module level with explicit `'pt-BR'` and, for dates, explicit `timeZone: 'America/Sao_Paulo'`.
- `fmtInt(v)`: `Intl.NumberFormat('pt-BR', {maximumFractionDigits: 0})`.
- `fmtDec(v, d)`: min = max fraction digits = d. `fmtG(v, d = 4)` = fmtDec (alias used for g values).
- `fmtPct(v, d = 1)`: percent style with d fraction digits.
- `fmtDate(d)`: `{day:'2-digit', month:'2-digit', year:'numeric'}`. `fmtTime(d)`: `{hour:'2-digit', minute:'2-digit', second:'2-digit', hourCycle:'h23'}`. `fmtDateTime(d) = fmtDate(d) + ' ' + fmtTime(d)`. Do NOT use dateStyle/timeStyle (gives a comma, see interfaces). Accept Date or epoch ms.
- `fmtDuration(seconds)`: `< 60` → `'${fmtDec(s, s % 1 ? 1 : 0)} s'`; otherwise `'${min} min ${fmtDec(rest,1 or 0)} s'`; hours form `'H h MM min'` for ≥ 3600.
- `fmtThreshold(v)`: `maximumFractionDigits: 4`, no forced decimals.
- `parseDecimal(text)`: `String(text).trim()`, regex `^\d+([.,]\d+)?$`, then `Number(t.replace(',', '.'))`, else NaN. No thousand separators accepted (strictness is the point; `parseFloat` alone is forbidden because `parseFloat('1,5abc')` → 1).
- `validateThresholds(vals)` → `{ ok, error: string|null, fieldErrors: boolean[4] }`. Rules in order: any NaN → mark those fields, error `'Informe números válidos (use vírgula ou ponto como separador decimal).'`; `vals[0] <= 0` → field 0, error `'O primeiro limiar deve ser maior que zero.'` (a zero threshold makes every sample an event; the engine accepts it so the UI must block it); any `> 16` → `'Os limiares devem ser no máximo 16 g (faixa do sensor).'`; any `vals[i] <= vals[i-1]` → mark field i, error `'Os limiares devem ser crescentes.'`.

Create `site/js/app/i18n.js` exporting a frozen `T` object of Portuguese strings used by the UI in Plans 05/06: page title (`'Monitoramento de Sapata Coletora — Painel da Corrida'`), loading/error texts (`'Carregando dados…'`, `'Não foi possível carregar os dados da corrida.'`), KPI labels (`registros`, `eventos`, `impactos`, `pontos de impacto`, `trecho com mais eventos`), section titles (Visão geral, Classes de severidade, Médias e máximos, Estatísticas por eixo, Qualidade dos dados, Limiares de severidade, Filtros, Exibição), filter labels (Sentido, Trecho, Eixo dominante, Classe, Janela de tempo, Todos), display labels (Valores: Medido / Dinâmico; Métrica do mapa de calor: Eixo dominante / AX / AY / AZ / Resultante dinâmica; Raio; Intensidade; note `'Usado pelo mapa (próxima etapa).'`), badge texts (`'Conforme planilha'`, `'Divergente da planilha'`, `'Classes, eventos, impactos e divisão por sentido iguais à planilha de referência.'`, pontos note `'Pontos de impacto: 99 aqui vs 101 na planilha (chaves de GPS diferentes); comparação apenas informativa.'` — build this one from a function `pontosNote(engine, ref)` that interpolates numbers via fmtInt rather than hard-coding 99/101), reset button (`'Restaurar padrões'`), quality labels (Cobertura GPS, Amostras sem posição, Canais vazios, Intervalo de retorno, Avisos dos arquivos de estações, `'nenhum aviso'`, Estações inferidas, Não classificadas), stats column headers (Média, Mediana, Desvio padrão, P0,5, P99,5, Maior valor absoluto), axis names (AX Longitudinal, AY Lateral, AZ Vertical, Resultante). Class names come from `CLASS_NAMES` in core/defaults.js (already Portuguese); do not duplicate them.
