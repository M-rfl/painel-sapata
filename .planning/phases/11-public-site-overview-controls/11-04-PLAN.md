```yaml
# Deploy dashboard (site/) to GitHub Pages. Deploy runs only after the test job passes.
# CI test selection: <decision from Task 1, one-line reason>
name: Publicar painel
on:
  push:
    branches: [master, main]
  pull_request:
  workflow_dispatch:
permissions:
  contents: read
jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@vX
      - uses: actions/setup-python@vX
        with: { python-version: '3.13', cache: pip }
      - uses: actions/setup-node@vX
        with: { node-version: '24' }
      - name: Instalar dependências de teste
        run: |
          sudo apt-get update && sudo apt-get install -y python3-tk xvfb   # only if full suite chosen
          python -m pip install -r requirements.txt -r requirements-dashboard.txt
      - name: Testes Python
        run: xvfb-run -a python -m pytest      # or the dashboard-only selection from Task 1
      - name: Testes do motor JS
        run: node --test "tests/js/*.test.js"
  deploy:
    if: github.event_name != 'pull_request'
    needs: test
    runs-on: ubuntu-latest
    permissions:
      pages: write
      id-token: write
    environment:
      name: github-pages
      url: ${{ steps.deployment.outputs.page_url }}
    concurrency:
      group: pages
      cancel-in-progress: false
    steps:
      - uses: actions/checkout@vX
      - uses: actions/configure-pages@vX
      - uses: actions/upload-pages-artifact@vX
        with: { path: site }
      - id: deployment
        uses: actions/deploy-pages@vX
```
Replace every `@vX` with the major tags from Task 1. Note: setup-python with python 3.13 + `cache: pip` needs a requirements file to hash — set `cache-dependency-path: | requirements.txt requirements-dashboard.txt`. Keep concurrency on the deploy job only so PR test runs are not serialized behind deployments. No `paths:` filter (a converter or data change must redeploy). Do not use `configure-pages` `enablement: true` (does not work with GITHUB_TOKEN); Pages source is set by the user in Plan 11-07. Do not add a package.json.
