Design decisions:
- Thresholds: 4 `<input type="text" inputmode="decimal">` labelled Leve ≥, Moderado ≥, Severo ≥, Crítico ≥ (g). Never `type="number"` (comma handling). On `input` → `store.set(s => setThresholdText(s, i, el.value))`. Fields with `thresholdFieldErrors[i]` get `.field-error` + `aria-invalid`; the error message is shown under the group. Re-render must NOT overwrite the field the user is typing in (only rewrite `value` when it differs from state text, and keep focus/caret) — controls are mounted once and updated via `renderControls`, not rebuilt.
- Filters: sentido checkboxes (names from run.sentidos); trecho multi-select as two checkbox groups by sentido in `order`; eixo chips X Longitudinal / Y Lateral / Z Vertical; classe chips with farol colours; time window = two `<input type="range">` over `[run.tMs[0], run.tMs[n-1]]` step 1000 ms with clock labels `fmtDateTime(t0 + tMs - tMs[0]…)` — compute the label as `new Date(Date.parse(meta.t0) + (tMs - run.tMs[0]))` and document the basis; full range maps to `null` (unbounded) in state so reset/default equality holds. "Todos" = empty selection (each group has a "limpar" link).
- Sentido filter uses the geofence sentido (11.835/11.548 split); add a small note: 'Divisão por sentido detectada pelas estações (a planilha usa a divisão por arquivo).'
- Display: Valores Medido/Dinâmico radio (drives the stats table); Métrica do mapa de calor select; Raio and Intensidade ranges with live value labels; note T 'Usado pelo mapa (próxima etapa).' — do not draw any map or heat map.
- Reset: button 'Restaurar padrões' → `store.reset()`; after reset every input reflects defaults (threshold texts '0,5','1','2','4').
- If the analyze timing logged in Plan 05 is > 50 ms, coalesce `update()` with `requestAnimationFrame`.
