  <name>Task 1: Pure report controller with soft map failure and busy guard</name>
  <files>site/js/app/reportaction.js, tests/js/report_action.test.js</files>
  <behavior>
`createReportAction({ getSnapshot, loadLib, buildReport, renderMap, renderPdf, download, now, onState })` returns `{ run(): Promise<result>, busy(): boolean }`; result = `{ status: 'ok' | 'warning' | 'error' | 'skipped', warnings: string[], error?: Error, filename? }`. Tests use fakes for every dependency.
    - ok: getSnapshot -> snap; loadLib awaited BEFORE renderMap; buildReport(snap, { now: now() }) called once with the injected clock value; renderMap(model.map.input); renderPdf(model, { jsPDF, autoTable, mapImage }) ; download(blob, model.filename) once with a Blob of type 'application/pdf' whose size equals bytes.byteLength; status 'ok', warnings []; onState sequence ['busy', 'idle'].
    - basemap failed: renderMap resolves { basemapFailed: true, ... } -> PDF still rendered with that mapImage, status 'warning', warnings ['basemap'].
    - map throws: renderMap rejects -> renderPdf called with mapImage null, download called, status 'warning', warnings ['map'].
    - total failure: loadLib rejects, or buildReport/renderPdf throws -> download NOT called, status 'error' with the error; onState still ends 'idle'.
    - busy guard: calling run() twice without awaiting -> second resolves { status: 'skipped' } and the dependencies run once; busy() true during, false after.
    - no snapshot: getSnapshot returns null -> 'skipped', nothing else called, onState not called.
    - The snapshot is taken exactly once, at the start of run() (getSnapshot call count 1 even if renderMap is slow).
    - A macrotask yield happens between onState('busy') and loadLib (inject `yieldFn`, default `() => new Promise((r) => setTimeout(r, 0))`; the test asserts the order busy -> yield -> loadLib).
  </behavior>
