New contract (consumed by plan 14-06; names/return shapes are FINAL):
```js
// site/js/app/session.js — pure: no document/window.
export function isShareable(run) // -> !(run && run.meta && run.meta.uploaded)
export function createDisposers() // -> { add(fn) -> fn, run() }: run() calls every added fn in REVERSE order, each in its own
//                                   try/catch (one failing disposer never skips the others; first error is console.error'd),
//                                   then clears the list, so run() is idempotent (second call is a no-op).
export function createSession(mount /* (run, opts) => { destroy() }; MUST clean up its own partial work before throwing */) // returns:
//   showExample(run, opts?)     -> bumps the generation, mounts bundled run (remembers it as example), opts passed to mount
//   async tryLoad(produce)      -> const gen = ++generation; produce: async () => Run.
//                                  After produce settles, if gen !== generation (a newer tryLoad/restoreExample/showExample
//                                  started meanwhile): return { ok:false, stale:true } — nothing destroyed/mounted, error swallowed.
//                                  produce threw (not stale): { ok:false, error } and NOTHING destroyed/mounted.
//                                  success: destroy current, mount(run, { uploaded: true }); if mount throws, remount the
//                                  previous run with its previous opts and return { ok:false, error }; if that remount ALSO
//                                  throws, current() becomes null and return { ok:false, error, fatal:true }; else { ok:true, run }
//   restoreExample()            -> bumps the generation (invalidates in-flight loads), destroy current, mount(example, { uploaded: false, fresh: true })
//   current()                   -> { run, uploaded } | null
//   busy()                      -> true while the latest tryLoad's produce is pending (stale ones do not count)
```
The generation token is the ONLY race protection: there is no cancellation of `produce` (conversion runs to completion and its result is dropped).
