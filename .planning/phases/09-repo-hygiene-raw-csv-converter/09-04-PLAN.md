  <behavior>
    - medians over integer LSB: odd n -> middle value; even n -> mean of the two middles (may be x.5)
    - dynamic = (lsb - median)/2048 per axis; dominant axis = max |dynamic|, ties X > Y > Z
    - classes lower-bound inclusive: |dom| exactly 0.5 g (1024 LSB above median) -> Leve (1); just below -> Normal (0); exactly 4 g -> Crítico (4)
    - evento = class >= 1; impacto = maximal run of consecutive evento rows in row order; impact class = max class in the run; impact_starts lists run start indices
    - ponto: key = loc_key if not None else 'SEM GPS | ' + trecho_name; per key the evento row with strict max |dom| (first wins on ties); points_by_class by the class of that row
    - per_trecho: records, eventos, impactos (attributed to the trecho of the impact's peak row, first max), pontos (by the point row's trecho)
    - rows with None accel are 'unclassified' (counted separately, not events, and they break impact runs)
  </behavior>
