## Decisions locked for this plan (state them in the SUMMARY)

1. **Threshold-to-integer rule: `th2 = math.ceil(t * 4096)`** (doubled-LSB). `dom2 >= ceil(t*4096)` is exactly "|dom| >= t g" for integer dom2, so lower bounds are inclusive at the g value. Defaults 0.5/1/2/4 give 2048/4096/8192/16384 (unchanged). JS uses `Math.ceil(t * 4096)`, the identical IEEE product. Write the literal `t * 4096`, not `t * ACCEL_PER_G * 2`.
2. **Manual offset quantization: `off2 = math.floor(g * 4096 + 0.5)`** (half-up onto the doubled-LSB grid, resolution 1/4096 g, which covers every possible half-LSB median). Never use Python `round()` (banker's rounding) or JS `Math.round` in rules. Define `half_up(x) = math.floor(x + 0.5)`.
3. **Gap budget:** `gap` = the maximum number of non-event rows (Normal OR unclassified) allowed between two consecutive events in the same impact. It is pure index distance: an event at row i joins the current impact iff `(i - last - 1) <= gap`. Default 0 = workbook.
4. **Time-jump split:** measured event-to-event: an event at row i starts a new impact if `t_ms[i] - t_ms[last] > max_jump_ms` (strict; exactly equal does not split). Default `max_jump_ms = 2000`. With `t_ms=None` the split is disabled, so the old call path is untouched. Research verified the max event-to-event dt on run 1 is 426 ms and 1000–5000 ms all give 1749. This plan re-asserts that with a test. If the test fails, STOP and report it. Do not tune the value.
5. **Sentido change and GPS do not affect grouping** (pure row order).
6. **Priority (impact basis):** per trecho, `max_cls` = max class over impacts whose PEAK row is in that trecho (0 if none). With `ncls = len(thresholds)+1`: level 1 (Alta) if `max_cls == ncls-1`, 2 (Média) if `== ncls-2`, 3 (Baixa) if `== ncls-3`, else 4 (Monitorar). `top_count` = number of those impacts with class `ncls-1`. `peak_dom2` = max dom2 over EVENT rows (cls >= 1) of that trecho, whole run, 0 if none. Sort key: `(level asc, top_count desc, peak_dom2 desc, order index asc)`.
