## Rules this plan must mirror (the plan 10-01 decisions; the oracle is the source of truth)
- Doubled-LSB: `dom2 = max_k |2*v_k - off2_k|`, strict `>` so ties go X > Y > Z. `domAxis` = the k that won (0/1/2), -1 if unclassified.
- `median2(values)`: sort a typed-array copy (numeric); n odd → `2*s[(n-1)>>1]`; n even → `s[n/2-1] + s[n/2]`; n == 0 → 0. Computed ONCE over the whole run, over valid values per axis (an axis value is "valid" if not null; the median of each axis uses all non-null values of that axis, exactly like Python `[v for v in a if v is not None]`).
- Offset: `{mode:'median'}` → off2 = med2; `{mode:'manual', g:[gx,gy,gz]}` → `off2 = halfUp(g*4096)`, `halfUp(x) = Math.floor(x + 0.5)`. Never use Math.round.
- `thresholds2(th_g) = th_g.map(t => Math.ceil(t * 4096))`; `cls = count of th2 <= dom2` (lower bound inclusive). The engine assumes strictly increasing thresholds (PARAM-01 enforces the order in the UI); document that unordered input is undefined.
- A row is unclassified if ANY of ax/ay/az is null: cls = -1, dom2 = 0, not an event.
- groupImpacts: one forward scan; skip `cls[i] < 1`; split if `cur === null || (i - last - 1) > gap || (tMs[i] - tMs[last]) > maxJumpMs`; peak update `dom2[i] > dom2[cur.peak]` (first maximum); class = max; record start, end, peak, cls, nEv. Unclassified rows count toward the gap (pure index distance).
- pointsByLocation: for event rows in ascending order, key = `locId[i] >= 0 ? locId[i] : -1 - trecho[i]` (equivalent to Python's `"SEM GPS | " + trecho_name`, provided that trecho names are unique per index); keep the row with strictly greater dom2 (first max wins); return the point rows sorted ascending.
- Location identity = coordinates, not fix index: build the key per GPS fix as `lat.toFixed(6) + ',' + lon.toFixed(6)` (same as Python `f"{lat:.6f},{lon:.6f}"`), mapped to dense ids with a Map. On run 1 the oracle gives pontos = 99, points_by_class [0,8,16,36,39] (the workbook says 101; that comparison is side by side only).

```js
  offset: Object.freeze({ mode: 'median' }), gap: 0, maxJumpMs: 2000 });
// data.js
export function expandRuns(runs, n, ArrayType = Int32Array)        // [[start, value], ...] -> typed array
export function fromArrays({ ax, ay, az, tMs, locKey, trecho, trechoNames, source }) -> Run
  // ax/ay/az: arrays of int|null; tMs: numbers; locKey: (string|null)[]; trecho: int idx[];
  // trechoNames: string[]; source: int[] | null (per-row source-file index, time order)
export function decodeRun(json) -> Run   // builds arrays from schema-v1 JSON, then calls fromArrays; adds extras
// Run = { n, ax, ay, az: Int32Array, valid: Uint8Array (1 = all three axes non-null),
//         axValid/ayValid/azValid: Uint8Array, tMs: Float64Array (cumulative dt_ms),
//         locId: Int32Array (-1 = no GPS), trecho: Int32Array, trechoNames: string[],
//         region: Int32Array | null (region index by first appearance of source index), nRegions,
//         // decodeRun extras:
//         sentido: Uint8Array, flags: Uint8Array, fix: Int32Array, meta, trechos, sentidos, stations,
//         reference: json.meta.workbook_reference ?? null }
// dynamics.js
export function halfUp(x)
export function median2(int32Values)
export function restOffset2(run, offset) -> { med2: [3 ints], off2: [3 ints] }
export function dominant(run, off2) -> { dom2: Int32Array, domAxis: Int8Array }
// classify.js
export function thresholds2(thresholds_g) -> number[]
export function classify(dom2, valid, th2) -> Int8Array   // -1 unclassified
// events.js
export function groupImpacts(dom2, cls, tMs, gap, maxJumpMs) -> Array<{start,end,peak,cls,nEv}>
export function pointsByLocation(dom2, cls, locId, trecho) -> Int32Array (sorted rows)
// engine.js
export function analyze(run, params = DEFAULT_PARAMS) -> Result
// Result (this plan): { params, med2, off2, mediansLsb (med2/2), th2, ncls, dom2, domAxis, cls,
//   naoClassificadas, classCounts: number[], eventos, impacts, impactos, impactsByClass: number[],
//   pointRows, pontos, pointsByClass: number[] }
// Plan 10-04 adds: perTrecho, priority, regionSplit, conforme.
// index.js: export * from each module.
```
