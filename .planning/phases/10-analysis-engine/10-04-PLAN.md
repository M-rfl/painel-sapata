## Rules (mirror Python oracle plan 10-01, decision 6)
- perTrecho(run, cls, impacts, pointRows) → array indexed by trecho idx (length trechoNames.length): `{records, eventos, impactos (by impact PEAK's trecho), pontos, maxCls (max impact class, 0 if none), topCount (impacts with cls === ncls-1), peakDom2 (max dom2 over EVENT rows cls>=1, 0 if none)}`.
- Level: `maxCls === ncls-1 → 1; === ncls-2 → 2; === ncls-3 → 3; else 4`. ncls = th2.length + 1 (follows the class index; no fixed g).
- trechoPriority → array of `{trecho, name, level, maxCls, topCount, peakDom2}` sorted by `level asc, topCount desc, peakDom2 desc, trecho idx asc` (trecho index = route order from the JSON `trechos`). Every trecho appears, including those with no impacts (level 4).
- regionSplit(run.region, run.nRegions, cls) → `{records: number[], eventos: number[]}` or null if region is null.
- Priority and conforme take the FULL run only. They have no filter argument by design (CONTEXT: filters never affect them). The divergence from the workbook text (pontos basis) is intentional: priority is NOT part of the parity-with-workbook check.

## conformeCheck(result, params, reference) contract
- `reference == null` → `{ available: false, ok: null, reasons: [] }`.
- Parameter reasons (in this order):
  - thresholds differ from `reference.thresholds_g` (element-wise numeric ===, same length) → `'limiares alterados'`
  - `params.offset.mode !== 'median'` → `'offset manual'`
  - `params.gap !== DEFAULT_PARAMS.gap` → `'agrupamento alterado'`
  - `params.maxJumpMs !== DEFAULT_PARAMS.maxJumpMs` → `'salto de tempo alterado'`
- KPI reasons (only for keys present in the reference): class_counts vs classCounts (`'classes'`), eventos, impactos, impacts_by_class (`'impactos por classe'`), sentido_records vs regionSplit.records (`'registros por sentido'`), sentido_eventos vs regionSplit.eventos (`'eventos por sentido'`). Format: `` `${label} ${fmt(actual)} ≠ ${fmt(expected)}` ``, where `fmt` uses `new Intl.NumberFormat('pt-BR')` and arrays are joined with '/'. Example: `'impactos 1.750 ≠ 1.749'`. If the reference has sentido_* but regionSplit is null → `'divisão por arquivo indisponível'`.
- Return `{ available: true, ok: reasons.length === 0, reasons }`. KPI diffs are always reported, even when params are non-default.
- Medians are NOT part of the check (CONTEXT list: classes, eventos, impactos, impacts_by_class, sentido splits).
