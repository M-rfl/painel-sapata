## E2E Flow

**Status: COMPLETE — no breaks found**

`python main.py` full flow verified by integration checker against source code:

1. `load_config()` → `AppConfig` (config.yaml, validation, defaults) ✅
2. `setup_logging(level=config.log_level)` → rotating file handler ✅
3. `CSVLogger(output_folder, prefix)` → timestamped CSV, 18-column header, flush ✅
4. `WitMotionSensor(config).connect()` → Modbus RTU on configured serial port ✅
5. Loop: `read_all_data()` → 19-register burst → `_parse_registers()` → `SensorReading` ✅
6. `csv_logger.write_row(reading)` → 18-cell row, None→"", flush ✅
7. `print(_format_reading(reading))` → terminal display per sample ✅
8. On read failure: `[WARN] Read failed - retrying...` → loop continues ✅
9. `KeyboardInterrupt` → session summary (samples, CSV path, elapsed) ✅
10. `finally: sensor.close(); csv_logger.close()` → unconditional cleanup ✅
